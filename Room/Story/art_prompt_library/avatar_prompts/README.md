# 核心角色头像提示词

用途：聊天框与资料卡的 `100 × 100 px` 方形头像。

统一视觉要求（每条提示词必须原样保留）：以用户提供的四格角色图为唯一风格锚点——干净的半写实日系角色卡插画，清晰而纤细的炭黑线稿，柔和赛璐璐分区明暗与轻微纸张纹理，明亮中性光，浅暖灰纯色背景，头肩近景。人物居中、头肩占画面 75–85%，缩小到 100 px 后仍可辨认。所有头像禁止摄影写实、油画厚涂、电影截图、3D 渲染、强戏剧布光、渐变场景背景、文字、卡片边框、气泡、Logo 或水印。

本批覆盖主线人物：张静祎、文兰、Zack、冯全、刘小雨、王教授、王小强，以及 Henry、Panny、Mark、周正。

阶段头像：张静祎与文兰各有“学生时期 / 后期”两张，供 `identityTimeline` 按剧情日期切换。Zack 与冯全已按最新设定重绘；旧图保留为历史版本，不覆盖。

不重复生成：Henry、Panny、Mark、周正（已有参考图），以及杨戬（已有角色符号）。
