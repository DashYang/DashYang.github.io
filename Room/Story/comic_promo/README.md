# 手机竖屏漫画宣传素材

本目录用于管理五位角色的手机竖屏漫画分镜。全局视觉规范、人物形象锁和分镜模板已经建立；Mark 篇已进入首轮图片预览阶段。

## 目录

```text
comic_promo/
├── STYLE_LOCK.md
├── SHOT_TEMPLATE.md
├── mark/
├── zhang_jingyi/
├── zhou_zheng/
├── zack/
└── wo/
```

每位角色目录包含：

- `CHARACTER_LOCK.md`：人物不可随分镜改变的身份特征，以及允许使用的时期变体。
- `shots/`：该角色作为主要人物的分镜描述和最终图片。

## 文件命名

每个分镜必须由一对同名文件组成：

```text
shot-001.md
shot-001.png
```

- Markdown 文件记录完整生成提示词、对白、旁白和连续性要求。
- PNG 文件是该分镜唯一的最终画面。
- 编号使用三位数字并在角色目录内递增。
- 修改现有分镜时保留 Markdown 中的历史说明；未经明确要求，不覆盖已确认的图片。

## 生成顺序

1. 复制 [`STYLE_LOCK.md`](./STYLE_LOCK.md) 中的 `GLOBAL STYLE LOCK`。
2. 复制出场人物各自 `CHARACTER_LOCK.md` 中的英文 `CHARACTER LOCK`。
3. 使用 [`SHOT_TEMPLATE.md`](./SHOT_TEMPLATE.md) 填写当前分镜。
4. 每个分镜单独调用一次图片生成，不把多个分镜合并为一张图。
5. 检查角色身份、单格构图与安全区后，将成图等比缩放并居中裁切为 `1080 × 1920 PNG`。
6. 将最终图片保存在对应角色的 `shots/` 中，并确保同名 Markdown 可追溯完整提示词。

## 固定原则

- 所有画面均为原创现代美式图像小说风格。
- 所有画面均为 `9:16` 手机竖屏单格分镜。
- 图片中默认不生成标题、对白、旁白或其他文字。
- 人物参考图只锁定身份，不继承参考图原有的日漫头像画风、方形构图或背景。
- 尚未确定剧情时，不创建分镜文件或占位图片；确定后的分镜按角色目录独立管理。
