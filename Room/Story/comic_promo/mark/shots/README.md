# Mark 篇：雾中来客

本目录保存 Mark 篇六个手机竖屏单格分镜。首轮美漫预览已经生成，每镜包含分镜 Markdown、无字底图和英文排版后的最终预览。

| 分镜 | 标题 | 画面文字 |
|---|---|---|
| `shot-001` | 无人游玩的游戏 | `SPEED BLOCKS`、三项零数据、`Zero?` |
| `shot-002` | 疲惫的 Mark | `No way` |
| `shot-003` | 装修噪音爆发 | `BRRRRRRRR—`、`LOUD DRILLING FROM UPSTAIRS`、`STOP!` |
| `shot-004` | 阳光突然暗淡 | `WTF?` |
| `shot-005` | 窗外大雾 | `DING-DONG`、`Mist?` |
| `shot-006` | 门外的人 | `Hello?` |

## 生成规则

- 每个分镜单独生成一张无字底图，不得合并成漫画整页。
- 图片生成提示词内继续使用 `Text (verbatim): none`。
- 所有可见文字均按分镜文件的“英文后期排版层”另行叠加。
- 最终画面只能出现分镜明确列出的英文，禁止中文、品牌文字和随机乱码。
- 无字生成原图按 `shot-001-base.png` 至 `shot-006-base.png` 保存，便于重新排版。
- 最终预览按 `shot-001.png` 至 `shot-006.png` 保存，并统一处理为 `1080 × 1920 PNG`。
