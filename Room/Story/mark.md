# Mark 人物立绘形象

## 基本信息

| 维度 | 内容 |
|---|---|
| **姓名** | Mark |
| **别名** | 奋斗的西瓜（微信昵称）、Mark、Mark 哥 |
| **年龄线** | 约 22 岁（2018 毕业）→ 约 29 岁（2025 独立游戏开发者） |
| **职业** | 互联网大厂员工 → 主管 → 被辞退 → 独立游戏开发者 |
| **出身** | 普通家庭，靠自己努力进入大厂 |
| **性格底色** | 一往无前、功利务实、在失去一切后开始反思 |

## 外貌气质关键词

- **典型的互联网人**——早期：朝气蓬勃的年轻工程师；中期：西装革履的中层管理，眼神越来越疲惫
- **有股说不出的傻劲**——张静祎的评价："他有种说不出的傻劲，有时候一往无前的"
- **加班脸**——黑眼圈，依赖咖啡吊命，"第二天起来都靠咖啡吊着一口气上班"
- **三个阶段的形象变化**：
  - **毕业生期（2018）**：青涩、踏实、有冲劲
  - **主管期（2020-2024）**：穿着讲究了，但眼睛里的光变成了计算和疲惫
  - **独立游戏开发者期（2025）**：被张静祎植入了新记忆，不再穿西装，居家服+胡子拉碴，在电脑前做游戏

## 人物弧光四阶段

### 第一阶段：追梦者（大学-初入职场 2018-2019）

普通家庭出身的大学生，毕业后进了大型互联网公司。一心想向女友文兰求婚，被张静祎劝住——"先工作几年再说吧"。**那时的他还有浪漫：听陈奕迅，个性签名是《人来人往》的歌词，相信努力就能换来幸福。**文兰说他是"不会太多想的人"——这种一根筋往前冲的性格，既是他的优点，也埋下了日后异化的种子。

### 第二阶段：异化者（主管期 2020-2024.5）

在大厂的晋升阶梯上节节攀升。他全身心投入的 AI Agent 项目大获成功——代价是招他进来的领导因"效率提升"被辞退，而他觉得"对他是好事，他就能上位了"。他开始用互联网黑话取代正常交流，对下属 Henry 的失踪轻描淡写——"耽误了不少进度，我只能想办法协调资源救火了"。**他变成了一个用 ROI 衡量一切的人，包括人命。**张静祎骂他："做个人吧。"文兰说："他变得越来越陌生了。"

### 第三阶段：被抹去者（催眠期 2024.6-2025.3）

文兰回槐阴村后失踪。他被公司辞退。一无所有之际，张静祎对他施了催眠术——抹去他关于文兰、Henry 和自己过去的记忆，植入新的人格。他变成了一个独居的独立游戏开发者，叫张静祎"姐姐"，忘了自己曾经结过婚、管过人、做过 AI。**他甚至忘了文兰是谁。**周警官来访时提到文兰，他茫然："文兰……文兰是谁？"

### 第四阶段：觉醒者（2025.3）

周警官和冯全的来访让他产生怀疑。他通过互联网搜索张静祎的信息，发现她不是自己的姐姐。记忆的裂缝一旦出现就止不住。他最终推理出全部真相——张静祎把他变成了另一个人。**但他没有愤怒。他说："你已经很棒了。我现在几乎确信了，这个世界就是存在不可思议之事。"**——一个曾经只信 KPI 和 ROI 的人，终于相信了有比逻辑更强大的东西。

## 立绘设计建议

**主构图思路**：Mark 坐在天阳小区 503 的窗边，三个时期的自我共处一室——

- **左侧（过去）**：刚毕业的 Mark，穿着廉价的西装，手里拿着求婚戒指盒，眼神坚定而天真
- **中央（现在）**：独立游戏开发者 Mark，穿着皱 T 恤和拖鞋，坐在电脑前，屏幕上显示极速方块游戏，旁边是一杯冷掉的咖啡
- **右侧（阴影中）**：主管 Mark 的轮廓，穿高领毛衣/商务休闲装，手里拿着手机正在处理工作消息，但脸在暗处——他已经不记得这段自己了
- **窗外**：天阳小区的夜色，隔壁楼的窗户透出诡异的光
- **桌上散落**：文兰留下的半个拼好的模型、一张陈奕迅的专辑封面、被揉皱的裁员通知
- **镜子/反射**：电脑屏幕的黑色反光中，隐约映出的不是他自己的脸，而是 Henry 和文兰的轮廓——被植入的记忆在暗处注视着他

**色调**：三个时期用三种色调——过去是暖黄色（希望），主管期是冷蓝色（理性和冰冷），现在是灰色调（迷茫），窗外透入暗绿色微光（灵异的渗透）。

**情绪表达**：不是撕心裂肺的痛苦，而是一种安静的茫然——"我是谁，我曾经是谁，我本该是谁？"

## 关键关系

| 人物 | 关系 |
|---|---|
| 文兰 | 妻子。大学起相恋，经历了他求婚→结婚→他变了→频繁吵架→她失踪。失去她是 Mark 所有转变的催化剂 |
| 张静祎 | 文兰的闺蜜→他的"姐姐"。她毁掉了他的人生，也给了他一个新的人生。他对她没有恨意——只有理解 |
| Henry | 下属/张静祎的弟弟。Mark 对他不冷不热，死后才意识到自己错过了什么 |
| Zack | 大学同学。Zack 事业成功（AI 国家级项目），Mark 成了独立游戏开发者——两人的人生轨迹形成了对照 |
| 周警官 | 调查者→命运的交叉点。周正见证了 Mark 从大厂主管到失忆者再到觉醒者的全过程 |
| Panny | 邻居。因为噪音互相指责。Panny 曾暗恋 Henry（虽然 Henry 暗恋的是她），形成了一种悲剧的三角 |
| 冯全 | 以异味风衣男的形态出现在 Mark 门口，咳嗽、发臭——一个濒临崩溃的驭鬼者。Mark 不知道他面对的是什么 |
